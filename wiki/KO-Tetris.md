# 테트리스 예제

예제 파일은 `examples/tetris.c`입니다.

## 빌드

```powershell
python .\famic.py build .\examples\tetris.c -o .\build\tetris.nes --asm .\build\tetris.asm
```

## 조작

### 타이틀 화면

- 왼쪽 / 오른쪽: 시작 레벨 1단계 변경(0~19, 순환)
- 위 / 아래: 시작 레벨 5단계 변경
- Start: 선택한 레벨로 게임 시작

### 플레이 중

- 왼쪽 / 오른쪽: 블록 이동(DAS 자동 반복)
- 아래: 소프트 드롭
- 위: 하드 드롭
- A: 시계 방향 회전
- B: 반시계 방향 회전
- Start: 일시정지/재개(BGM도 같은 위치에서 멈췄다가 이어서 재생)

### 이름 입력

최고 점수 3위 안에 들면 나타납니다.

- 위 / 아래: 선택된 글자 변경(공백, A~Z)
- 왼쪽 / 오른쪽 또는 A: 글자 위치 이동
- Start: 확정 후 타이틀 화면으로 복귀

## 예제에서 보여주는 기능

- 다중 팔레트, 입체 음영 블록, 방향성 테두리와 대형 타이틀 로고로 구성한 NES UI
- ROM 테이블 기반 블록 모양 데이터와 공정하게 섞이는 7-bag
- 16비트 LFSR 상태를 매 프레임 진행하고 입력 타이밍을 반영하는 블록 순서
- 보드 배열과 충돌 판정
- 고정 회전축을 기준으로 한 정확한 회전. T, J, L은 4방향, I, S, Z는 2방향,
  O는 회전하지 않습니다. 거울상으로 뒤집히는 상태가 없습니다.
- 1칸 및 2칸 벽 킥, 잠금 지연, 라인 삭제 연출
- 시작 레벨 선택과 3위까지 기록되는 이름 입력 최고 점수표
- 이동, 회전, 드롭, 착지, 라인 삭제, 레벨 업, 메뉴, 게임 오버 효과음.
  BGM을 끊지 않고 함께 재생됩니다.
- NEXT, 점수, 라인, 레벨, TOP 패널, 레벨별 중력
- 타이틀, 플레이, 일시정지, 게임 오버, 이름 입력 상태
- 패드 입력 처리
- vblank에 맞춘 PPU 업데이트
- 네이티브 큐 렌더러를 통한 빠른 활성 블록 갱신
- MIDI의 전체 음악 구간 4분 26.127초를 2A03의 펄스 2채널, 트라이앵글,
  노이즈로 편곡한 BGM(원본 4분 29.605초에는 도입부 무음 포함)

## 회전 규칙

`SHAPES`는 회전 상태마다 4행을 저장하며, 한 행이 4비트이고 최상위 비트가
0번 열입니다. 모든 상태는 스폰 상태를 고정 회전축 기준으로 시계 방향으로
돌린 결과이며 거울상이 아닙니다. 따라서 회전 도중 블록 모양이 바뀌거나
회전축에서 밀려나는 일이 없습니다.

- T, J, L은 3x3 상자의 중앙 칸을 축으로 4개 상태를 모두 사용합니다.
- I, S, Z는 고전적인 2상태 방식이라 두 번 회전하면 원래 자리로 정확히
  돌아옵니다.
- O는 상태가 하나뿐입니다.

회전은 제자리 → 왼쪽 1칸 → 오른쪽 1칸 → 왼쪽 2칸 → 오른쪽 2칸 순으로
시도합니다. 2칸 킥 덕분에 세로 I 블록이 양쪽 벽에 붙어 있어도 회전할 수
있습니다.

## 효과음

`sfx_play(id)`가 런타임 효과음 재생기를 구동합니다. 각 효과음은
`SFX_START`와 `SFX_LENGTH`가 가리키는 `SFX_CTRL`, `SFX_TIMER_LO`,
`SFX_TIMER_HI`의 프레임 단위 구간을 재생합니다. 재생 중에는 BGM에서
펄스 2 채널만 잠시 빌려 쓰고 끝나면 돌려주므로, 펄스 1과 트라이앵글,
노이즈는 끊기지 않습니다. 테이블 규약은 [C 언어](KO-C-Language) 문서를
참고하세요.

## 최고 점수

3개 항목을 RAM에 보관하며 각각 3글자 이름과 6자리 점수를 가집니다.
초기값은 `FMC 010000`, `NES 005000`, `TOP 002500`입니다. 배터리 백업이
없으므로 전원을 껐다 켜면 초기화됩니다. 1위 점수는 게임 화면의 TOP
패널에도 표시됩니다.

## 검증

Mesen 2.2.1의 헤드리스 테스트 러너는 다음 동작을 검사하도록 구성되어 있습니다.

- 초기 화면 정상 표시
- 타이틀 레벨 선택 기본값
- 자연 낙하
- 좌우 이동
- 회전 여백이 있는 블록도 보드 맨 왼쪽 0열까지 이동
- 소프트 드롭
- 양방향 회전과 하드 드롭
- 블록 락과 다음 블록 스폰
- 라인 삭제 후 보드 RAM 200칸과 화면 타일의 일치
- NEXT 미리보기의 정렬과 원자적 vblank 갱신
- TOP 패널과 상태 표시줄의 내용
- 일시정지와 재개
- BGM 시퀀서 진행
- 화면 밀림과 잔상 제거
- 플레이 구간 전체에 걸친 렌더링 중 PPU 쓰기 방지
