# 언어 레퍼런스

FAMI-C는 C의 부분집합에 `asset` 선언 하나를 더한 언어다.
포인터가 없다는 점만 빼면 평범한 C처럼 쓰면 된다.

---

## 1. 타입

| 이름 | 폭 | 범위 | C 표기 |
|------|----|------|--------|
| `u8` | 8비트 | 0 ~ 255 | `unsigned char`, `char` |
| `i8` | 8비트 | -128 ~ 127 | `signed char` |
| `u16` | 16비트 | 0 ~ 65535 | `unsigned int`, `unsigned`, `unsigned short` |
| `i16` | 16비트 | -32768 ~ 32767 | `int`, `short` |
| `void` | — | — | `void` |

**`u8/i8/u16/i16`을 쓰라.** 폭이 이름에 있으면 틀릴 일이 없다.

`bool`은 `u8`의 별칭이다. 0이 거짓, 그 외가 참.

### 산술 승격

C와 같다. 8비트끼리의 `+ - * <<`는 **16비트로 승격된 뒤** 계산된다.

```c
u8  a = 30;
u16 wide  = a * 100;    /* 3000  — 잘리지 않는다 */
u8  narrow = a * 100;   /* 184   — u8에 넣는 순간 잘린다 (C와 동일) */
```

결과를 8비트에 넣는 게 확실하면 컴파일러가 8비트로 계산한다.
그래서 `u8 i = i + 1;`은 여전히 1바이트 덧셈 하나다.

부호가 섞이면(`u8` vs `i8`) 16비트로 올라간다. 한 바이트 안에서는
`200 > -5` 같은 비교에 정답이 없기 때문이다.

### 부호 있는 나눗셈

`i8`/`i16`의 `/`와 `%`는 **2의 거듭제곱으로 나눌 때만** 지원한다
(`v / 2`, `v / 16`은 산술 시프트가 된다). 그 밖에는 `E0402`가 난다:

```c
i8 dx;
u8 half = abs8(dx) / 3;     /* 절댓값으로 나누고 */
if (dx < 0) half = 0 - half; /* 부호를 다시 붙인다 */
```

## 2. 선언

### 변수

```c
u8  lives = 3;              /* 전역. 초기값은 시작 시 RAM에 복사된다 */
u16 score;                  /* 초기값 없으면 0 */
u8  board[200];
u8  grid[15][16];           /* 다차원 배열: grid[y][x] */

const u8 TABLE[5] = { 9, 8, 7, 6, 5 };   /* ROM에 들어간다. RAM을 쓰지 않는다 */
```

`const` 배열은 ROM(PRG)에 놓인다. 바꿀 수 없고(`E0305`), RAM 예산을 먹지 않는다.
**바뀌지 않는 표는 전부 `const`로 두라.** RAM은 1280바이트뿐이다.

지역 변수도 쓸 수 있지만 **정적으로 할당된다**(재귀 불가). 지역 배열은 되지만
초기값은 줄 수 없다(`E0301`) — `const` 전역으로 옮기면 된다.

### struct

멤버는 스칼라(또는 고정 크기 배열)만 된다. 컴파일러가 배열의 배열로 편다.

```c
struct Actor {
    u8 x;
    u8 y;
    i8 vy;
    u8 alive;
};

struct Actor hero;          /* -> _g_hero__x, _g_hero__y, ... */
struct Actor foes[8];       /* -> _g_foes__x[8], _g_foes__y[8], ... */

hero.x = 60;
foes[i].vy = foes[i].vy + 1;
```

- 구조체를 함수 인자로 넘길 수 없다. 전역 배열 + 인덱스를 쓰라.
- 구조체 통째 대입은 안 된다. 멤버마다 대입하라.
- 중첩 구조체는 안 된다. 멤버를 펴서 쓰라(`pos_x`, `pos_y`).

### enum / typedef

```c
enum { ST_TITLE, ST_PLAY, ST_OVER };
enum { LEFT = 1, RIGHT = 2 };

typedef u8 tile_t;
typedef struct { u8 x; u8 y; } Point;
```

### 함수

```c
u8 clamp(u8 v, u8 lo, u8 hi) {
    if (v < lo) return lo;
    if (v > hi) return hi;
    return v;
}
```

- 인자와 지역 변수는 **고정 주소**에 놓인다. 그래서 **재귀는 불가능**하다.
- 배열은 인자로 넘길 수 없다. 전역 배열을 직접 참조하라.
- 인자 계산 중에 다른 함수를 불러도 안전하다 (스택에 쌓았다가 옮긴다).
  단, 같은 함수를 재귀적으로 부르는 것만은 안 된다.
- 실행은 `void main(void)`에서 시작한다.

## 3. 문장

전부 표준 C다.

```c
if (a) { } else if (b) { } else { }
while (cond) { }
do { } while (cond);
for (i = 0; i < n; i++) { }
switch (v) { case 0: ... break; default: ... break; }
break;  continue;  return v;
```

`switch`는 case를 위에서부터 비교한다. `case` 라벨은 컴파일 시각 상수여야 한다
(숫자, `enum`, `#define`, asset 이름).

`goto`는 없다(`E0203`). 상태 변수와 `switch`로 대신하라.

## 4. 식

| 분류 | 연산자 |
|------|--------|
| 산술 | `+ - * / %` |
| 비트 | `& \| ^ ~ << >>` |
| 비교 | `== != < <= > >=` |
| 논리 | `&& \|\| !` (단축 평가) |
| 대입 | `= += -= *= /= %= &= \|= ^= <<= >>=` |
| 증감 | `++ --` (전위·후위) |
| 기타 | `?:`, `(타입)캐스트`, `sizeof`, `배열[i]`, `구조체.멤버`, `함수()` |

**없는 것:** `*`(역참조), `&`(주소), `->`, 쉼표 연산자, 복합 리터럴, 가변 인자.

### 문자열 리터럴

두 곳에서만 쓸 수 있고, 둘 다 **폰트 타일 인덱스 배열**이 된다.

```c
bg_text(2, 3, "SCORE");             /* 인자로 */
const u8 MSG[] = "GAME OVER";       /* const 배열 초기값으로 */
```

인접한 리터럴은 이어붙는다: `"HELLO " "WORLD"`.

## 5. 전처리기

```c
#include <fami.h>
#include "shared.c"

#define MAX_FOES 4
#define DOUBLE(v) ((v) * 2)         /* 함수형도 된다 */
#undef MAX_FOES

#ifdef DEBUG
#endif
#ifndef X
#endif
#if MAX_FOES > 2
#elif ...
#else
#endif

#pragma ...                          /* 무시된다 */
#error 메시지
```

**모르는 지시문은 조용히 넘어가지 않고 에러(`E0105`)다.** 조용히 버려진 지시문은
프로그램의 의미를 바꾸면서 아무 신호도 남기지 않기 때문이다.

함수형 매크로의 인자는 치환될 때 자동으로 괄호가 붙는다.

## 6. 메모리 배치

| 영역 | 크기 | 무엇이 들어가나 |
|------|------|----------------|
| 제로페이지 `$10-$FF` | 240B | 런타임 내부 변수, 식 계산용 임시 |
| 스택 `$0100-$01FF` | 256B | 서브루틴 복귀 주소, 식 중간값 |
| 섀도 OAM `$0200-$02FF` | 256B | 스프라이트 (`spr_*` 사용 시) |
| 일반 RAM `$0300-$07FF` | 1280B | **전역·지역·인자 전부** |
| PRG ROM `$8000-$FFFF` | 32KB | 코드 + `const` 데이터 + 런타임 |
| CHR ROM | 8KB | 타일 256장 |

빌드할 때마다 사용량이 출력된다:

```
OK  PRG 32768/32768 바이트  타일 81/256  RAM 743/1280  ZP 77/240
```

RAM이 모자라면(`E0309`):
- 안 바뀌는 표를 `const`로 → ROM으로 이동
- `u16`을 `u8`로
- 동시에 쓰지 않는 배열을 하나로 합치기

### 심볼 이름

`build/game.sym`에 들어가는 이름 규칙이다. `famic run --sym`에 그대로 쓴다.

| C에서 | 심볼 |
|-------|------|
| 전역 `score` | `_g_score` |
| `u16` 전역의 상위 바이트 | `_g_score+1` |
| `u16` 배열 `t[]` | `_g_t` (하위) / `_g_t__hi` (상위) |
| 구조체 `hero.x` | `_g_hero__x` |
| 구조체 배열 `foes[i].x` | `_g_foes__x` (i가 인덱스) |
| `const` 배열 `TABLE` | `_r_TABLE` |
| 지역 `main`의 `i` | `_l_main_i` |
| 인자 `clamp`의 `v` | `_p_clamp_v` |
| 함수 `update` | `_f_update` |

## 7. 지원하지 않는 것과 그 이유

| 없는 것 | 이유 | 대신 |
|---------|------|------|
| 포인터 | 6502의 간접 접근은 제로페이지를 먹고, 잘못 쓰면 디버그가 불가능하다 | 배열 + 인덱스 |
| 재귀 | 6502 스택은 256바이트뿐 | 반복문, 명시적 스택 배열 |
| 부동소수점 | 하드웨어 지원이 없다 | 고정소수점 (`docs/agent/HARDWARE.md`) |
| 표준 라이브러리 | ROM 32KB에 넣을 자리가 없다 | 런타임 API |
| 가변 인자 | 스택 프레임이 없다 | 고정 인자 |
| 매퍼 0 외 | 뱅크 스위칭은 에이전트 실수 비용이 너무 크다 | 32KB 안에서 해결 |
| `goto` | 흐름 추적이 어려워진다 | 상태 변수 + `switch` |
