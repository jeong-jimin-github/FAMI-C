Quick Start

Requirements

  • Python 3.10 or newer
  • Windows PowerShell, macOS shell, or Linux shell
  • Nothing else - the headless NES used for testing ships with the compiler

Build An Example

python famic.py build examples/tetris.c -o build/tetris.nes
python famic.py build examples/platformer.c -o build/platformer.nes

Check it without an emulator:

python famic.py screen build/tetris.nes --frames 30
python famic.py run build/tetris.nes --frames 300 --sym "_g_score:16"

Run Tests

python -m unittest discover -s tests -t .

The suite compiles programs, runs them on the bundled headless NES, and reads the results back out of RAM by symbol name.

Compiler Architecture

C sourceLexer and parser
ASTTyped 8/16-bit model, asset declarations
6502 assemblyStatic locals, runtime library calls
PRG ROMBuilt-in 6502 assembler
iNES ROMNROM-256 mapper 0 package

FAMI-C is intentionally self-contained. The compiler emits assembly, the assembler resolves labels and vectors, and the packager writes a 32 KB PRG + 8 KB CHR iNES image.

Supported C Model

Supported

  • u8, i8, u16, i16, void - real 16-bit arithmetic with C promotion rules
  • struct (lowered to parallel arrays), enum, typedef, multi-dimensional and local arrays
  • if, else, while, do, for, switch, break, continue, return
  • String literals, function-like macros, #include, #if
  • const ROM tables, and asset declarations for tiles, palettes, maps and sound

NES Runtime API

Built in. Nothing to declare - calling a function is what pulls its 6502 routine into the ROM.

wait_vblank();  frame_count();  ppu_on();  ppu_off();
pad_poll();  pad_held(0);  pad_pressed(0);  pad_released(0);
bg_tile();  bg_rect();  bg_text();  bg_char();  bg_number();
bg_attr();  bg_meta();  bg_map();  bg_clear();
spr_clear();  spr();  spr_meta();  spr_meta_flip();
scroll_set();  pal_load();  pal_set();  pal_bright();
mul8();  div8();  mod8();  abs8();  rand();  rand_range();
box_hit();  sfx_play();  music_play();  music_stop();

Current Limits

  • Locals are statically allocated; recursion is not supported.
  • No pointers, varargs, floating point, or libc.
  • Signed division is limited to powers of two.
  • Generated ROMs target mapper 0 / NROM-256: 32 KB PRG, 256 tiles, 1280 bytes of RAM.

Example: Tetris

The example in examples/tetris.c demonstrates static arrays, ROM lookup tables, controller polling, collision checks, line clearing, and vblank-safe PPU updates. Its presentation uses per-level palettes, seven distinct block patterns, a framed well, a next-piece preview, a start-level picker, and a best-player table with name entry.

Controls

  • Title: Left / Right picks the start level by one, Up / Down by five
  • Left / Right: move piece
  • Down: soft drop
  • Up: hard drop
  • A / B: rotate clockwise / counter-clockwise
  • Start: begin, pause/resume, or confirm a best-score name

NES Presentation and Systems

  • Fair 7-bag driven by a 16-bit LFSR and controller/input timing
  • Rotation states that are true rotations about a fixed pivot, never mirrored
  • Start-level picker and a three-entry best-player table with name entry
  • Sound effects that borrow pulse 2 from the song and hand it back
  • Multi-palette beveled UI with a NEXT preview, TOP panel, and line-clear flash
  • Full 4:26.127 musical section arranged for all four 2A03 channels
  • Source MIDI: 4:29.605 including the initial silence

Example: Platformer

The example in examples/platformer.c draws its stage as background metatiles - 16 cells across, 15 down, with cell row 0 as the status bar - so one cell is at once the unit of level storage and one attribute quadrant, and every cell picks its own background palette. The hero and the patrols are hardware sprites on top of it.

Actors move in pixels rather than in cells. Positions are 12.4 fixed point: a pixel byte plus a sixteenth-of-a-pixel accumulator, so a speed like 1.25 px per frame is exact and the motion is smooth. Vertical motion is a real velocity with gravity, which gives the jump its arc and makes its height depend on how long A is held. 

python .\famic.py build .\examples\platformer.c -o .\build\platformer.nes --asm .\build\platformer.asm

Controls

  • Left / Right: walk
  • B held: run
  • A: jump; release during the rise to cut it short
  • Start: begin a game, or restart after a game over

NES Presentation and Systems

  • Four stages of gems, patrols, spike pits, bottomless gaps and an exit door
  • Subpixel motion: 1.25 px per frame walking, 2 running, and about 54 px of jump
  • Gravity-driven jump with variable height and full mid-air control
  • A hitbox inset from the 16x16 sprite, so a one-cell gap is comfortable to pass
  • Stomping a patrol while falling squashes it and bounces the hero
  • Per-cell attributes packed from the level map when a stage loads
  • A shadow OAM refilled every frame and copied out by the NMI with $4014
  • A redraw queue flushed at most six tiles per vblank, so the PPU is never written late
  • Sound effects for jumps, landings, gems, stomps, damage, stage clears and game over
  • Title, stage intro, play, death, stage clear, game over and all-clear screens

한국어 문서

FAMI-C 사용 방법

FAMI-C는 NES/패미컴 프로그램을 C로 작성하기 위한 작은 툴체인입니다. 목적은 최신 데스크톱 C 전체를 6502에 억지로 옮기는 것이 아니라, 실제 NES 개발에 필요한 정적 메모리, 8비트 연산, PPU/패드 런타임을 단순하게 제공하는 것입니다.

  1. 소스 파일을 examples 또는 별도 폴더에 작성합니다.
  2. #include <fami.h> 후 main(void)을 구현합니다.
  3. python famic.py build source.c -o build/game.nes으로 빌드합니다.
  4. Mesen 같은 에뮬레이터에서 .nes 파일을 엽니다.

빌드 없이 결과만 보고 싶다면 브라우저 에뮬레이터에서 두 예제 ROM을 바로 실행할 수 있습니다. 직접 빌드한 .nes 파일도 열어서 확인할 수 있으며, 파일은 브라우저 밖으로 전송되지 않습니다.

전체 문서는 AGENTS.md에 있습니다. 언어 레퍼런스는 LANGUAGE.md, 런타임 API는 API.md를 보세요.

日本語ドキュメント

FAMI-C の使い方

FAMI-C は NES / ファミコン向けの小さな C ツールチェーンです。 6502 に合わせた 8 ビット ABI、静的メモリ、PPU 更新、コントローラー入力を シンプルな C サブセットから扱えるようにします。

  1. C ソースに main(void) を実装します。
  2. #include <fami.h> してランタイム関数を呼ぶだけです。
  3. python famic.py build source.c -o build/game.nes を実行します。
  4. Mesen などのエミュレーターで生成された ROM を開きます。

ビルドせずに動きを見たい場合は、ブラウザーエミュレーターで 2 つのサンプル ROM をそのまま実行できます。自分でビルドした .nes も 開けます。ファイルはブラウザーの外に送信されません。

English Documentation

How To Use FAMI-C

FAMI-C is a compact C toolchain for NES / Famicom programs. It favors a practical 8-bit programming model over full hosted ISO C, making it suitable for small mapper-0 games and demos.

  1. Write a C source file with main(void).
  2. #include <fami.h> and just call the runtime functions.
  3. Run python famic.py build source.c -o build/game.nes.
  4. Open the generated ROM in Mesen or another NES emulator.

To see the output before installing anything, run both example ROMs in the browser emulator. It also opens a .nes file you built yourself, without sending it anywhere.

The full documentation lives in AGENTS.md (Korean).
